# Games Collection

This repository contains interactive games developed for fun and practice.

## 1. Saints Timeline Game

A fun, interactive timeline game where you place saints in the correct chronological order based on their lives.

### How to Play (Saints)

#### Option 1: Play Online (Recommended)
This game is hosted using GitHub Pages. To play:
1. Go to the **Settings** tab of this repository.
2. Click on **Pages** in the left sidebar.
3. Under **Branch**, select the appropriate branch and the folder `/ (root)`.
4. Click **Save**.
5. After a minute, your game will be live at `https://<your-username>.github.io/<repository-name>/index.html`.

## 2. 5-6-7-8: Ballroom Rhythm & Style Trainer

A trainer for ballroom dancers to identify dance styles by music and practice hitting the "1-beat" precisely.

### How to Play (5-6-7-8)

1. Follow the GitHub Pages setup above.
2. The game will be live at `https://<your-username>.github.io/<repository-name>/5-6-7-8/index.html`.
